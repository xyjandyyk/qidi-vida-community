# 1.2.0-offline-v6（152）

新增 GitHub 社区版本更新，保留 v5 的连接、相册、运动记录和日志修复。

- App 进入首页时检查新版，同一次运行最多每 15 分钟检查一次。
- 手动入口：我的 → 关于 → 版本更新。
- 显示新版信息、下载进度，支持取消及重试。
- 下载后验证大小、SHA-256、包名、版本号和固定签名证书，再打开 Android 系统安装确认页。
- 与之前社区版本同签名，覆盖安装保留数据。

更新依赖手机能够访问 GitHub。网络不可用时会提示重试，不影响蓝牙和本地功能。此版本提供前台更新检查；不包含 App 关闭时的实时推送，也不包含私密日志上传。

v5 用户需手动安装一次本版本，之后可以通过 App 更新。v6-rc1 仅用于维护者手机验证，不作为群内发布版本。

## 当前验证情况

已验证同签名候选版覆盖安装、首页与更新页面可打开，以及 17 项清单和下载来源校验。正式包已校验签名，GitHub 附件哈希与本地一致。

完整的“App 发现新版 → 下载 → 系统覆盖安装”仍待实机验收：测试手机直连 GitHub 超时，后续安装还需要在手机输入锁屏密码。因此本次发布可用于群测，不能视为所有机型在线更新均已通过。
